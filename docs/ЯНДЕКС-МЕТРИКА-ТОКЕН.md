# Как получить OAuth-токен Яндекс.Метрики (для офлайн-конверсий amo→Метрика)

Нужен токен с правом **записи** в Метрику. Делается один раз, токен живёт ~1 год.
Аккаунт Яндекса — **тот, которому принадлежит счётчик 109717932**.

## Шаг 1. Создать приложение в Яндекс OAuth
1. Зайти на **https://oauth.yandex.ru/client/new** (под нужным аккаунтом Яндекса).
2. Название: `sato-metrika` (любое).
3. Платформа → **Веб-сервисы**. Redirect URI: `https://oauth.yandex.ru/verification_code`.
4. Доступы (Data access) → найти **«Яндекс.Метрика»** и отметить:
   - `Просмотр статистики, чтение параметров своих и доверенных счётчиков` (`metrika:read`)
   - `Запись, изменение параметров своих и доверенных счётчиков` (`metrika:write`) ← обязательно
5. Создать. Скопировать **ClientID** приложения.

## Шаг 2. Получить access_token (implicit flow — без сервера)
1. Открыть в браузере (подставив свой ClientID):
   ```
   https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID
   ```
2. Подтвердить доступ.
3. Яндекс перекинет на страницу, в адресе будет `#access_token=AQAA...&token_type=bearer&expires_in=...`.
4. Скопировать значение **access_token** (строка вида `y0_AgAAAA...` или `AQAA...`).

## Шаг 3. Отдать токен мне (или вписать самому)
Я впишу в `/etc/sato/amo.env` строку:
```
YANDEX_METRIKA_TOKEN=<токен>
```
и перезапущу `sato-api`. Проверка:
```
cd /opt/sato && sudo -u www-data HOME=/var/lib/sato venv/bin/python metrika.py <любой_ClientID> 800
# enabled: True  /  result: True
```

## Шаг 4. Создать цель в Метрике
Метрика → счётчик 109717932 → **Цели** → создать цель:
- Тип: **JavaScript-событие**
- Идентификатор: **`purchase`** (точно так, совпадает с `YANDEX_METRIKA_TARGET`)
- Название: «Оплата (офлайн-конверсия из amo)»

После этого: при переводе сделки в «Успешно — оплачено» backend автоматически
шлёт в Метрику конверсию `purchase` с суммой тарифа и ClientID клиента →
в отчётах Метрики/Директа видно, **какой источник/кампания принесли оплату и сколько денег**.

## Что уже работает без токена
- Захват ym_client_id + UTM + yclid с сайта → в сделку amo (кастом-поля).
- Дашборд `/dash` → «Источники трафика»: лиды/оплаты/выручка по источникам (по нашей БД).
- Цель `lead_submit` шлётся с сайта при отправке формы.
Токен включает **только** обратную отправку оплат в Метрику (офлайн-конверсии).
